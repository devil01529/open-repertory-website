DESIGNED FOR REFERENCE AND REVIEW

A focused repertory workflow.

Repertory search

Browse chapters, follow rubric hierarchies and inspect remedy gradations. Work with available books including Kent, Boericke and Therapeutic Pocket Book editions.

Repertorisation and analysis

Build a rubric selection, review symptom totality and compare remedies in ranking and matrix views. Keep the clinician in control of every case selection.

Materia medica library

Read available remedy profiles, explore reference sections and compare text with your selected rubrics. Repertory and materia medica remain connected in the workflow.

Android and web

Use the web workspace in a browser or install the Android app. The APK includes local repertory data, encrypted phone records and optional Smart Search with your own AI API key.

PRIVATE BY DESIGN

Clinical work stays behind sign-in.

The website uses initials-only cases saved in your browser, with a maximum of five cases and confirmation before replacing the oldest. Clinical case content is not stored in the server database. Account, approval and security records are stored to operate access.

The Android app keeps its records encrypted on the phone. Browser and APK records are separate; signing in does not automatically synchronize clinical records.

How do I get access?

Create a Similora account, then wait for owner approval. Existing approved users can sign in to the clinical workspace.

Is this the former Open Repertory?

Yes. Similora is the name of the clinical software previously called Open Repertory. It provides a homoeopathic repertory and reference-reading workflow.

Who is it for?

Clinicians using homeopathic reference literature. Search and analysis are reference aids requiring professional review; they do not establish a diagnosis or replace medical assessment.
